# FriendMap

Shows your friends on the world map and the minimap, as long as they run FriendMap too.

## Setup

1. Type `/friendmap` to open the settings.
2. Enter a channel name and, optionally, a password. Press Enter after each.
3. Share both with your friends and have them enter the same.

Only friends in the same channel see each other. FriendMap does nothing until a channel is set.

To see guild members instead, use GuildMap.
