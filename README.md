# FriendMap

Shows your friends on the world map and the minimap, as long as they run FriendMap too.

FriendMap finds out on its own which of your online friends run it. There is nothing to set up.

## Blocking

Type `/friendmap` to open the settings and pick a friend under Block friend. Only character friends
of your faction are listed. A blocked friend never gets your position, and you never see theirs.
Remove a name from the list to unblock them.

Only character friends are shown, not Battle.net friends.

To see guild members instead, use GuildMap.
